# ATM Simulator System

## Overview

ATM Simulator System is a desktop-based banking application developed using Java Swing, JDBC, and MySQL. The project simulates the core functionalities of an Automated Teller Machine (ATM), allowing users to perform banking operations through an interactive graphical user interface.

## Features

* User Registration and Account Creation
* Secure Login Authentication
* Cash Deposit
* Cash Withdrawal
* Balance Enquiry
* Mini Statement Generation
* PIN Change Functionality
* Transaction History Management
* User-Friendly GUI using Java Swing

## Technologies Used

* Java
* Java Swing
* JDBC (Java Database Connectivity)
* MySQL
* Apache NetBeans IDE

## How to Run

### Prerequisites

* Java JDK 8 or above
* MySQL Server
* Apache NetBeans (Optional)

### Steps

1. Clone the repository

```bash
git clone https://github.com/Rupesh963/ATM-Simulator-System.git
```

2. Create a MySQL database.

3. Import the required tables.

4. Update database credentials in the project.

5. Run the application from NetBeans or execute the generated JAR file.
